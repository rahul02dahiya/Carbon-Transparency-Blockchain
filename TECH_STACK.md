# Technology Stack & Architecture

## 1. Sensor & Data Layer
- **Source:** Simulated IoT Sensors (tracking CO2, NOX, and SOX).
- **Role:** Real-time data gathering from industrial assets.

## 2. Blockchain Layer (Backend Ledger)
- **Platform:** Ethereum (Standard for M.Tech research frameworks).
- **Logic:** Solidity (for Smart Contract development to handle carbon credits).
- **Consensus:** Proof of Stake (PoS) for energy-efficient verification.

## 3. Application Layer (Team Lead: Java)
- **Language:** Java (JDK 17+) – identified as a high-demand M.Tech sub-domain.
- **Framework:** Spring Boot (for enterprise-grade system architecture).
- **Blockchain Integration:** Web3j (Library to connect Java middleware to Ethereum nodes) [Note: Industry standard, not in source].

## 4. Analytics & Simulation Layer
- **Language:** Python (for data cleaning and predictive modeling of emission trends).
- **Tools:** MATLAB/Simulink (for system performance analysis).

## 5. Business Layer
- **Role:** Dashboards to provide a visual representation of "Green" compliance for facility management.
