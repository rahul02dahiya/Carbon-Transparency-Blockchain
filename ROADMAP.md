# Project Roadmap (M.Tech Thesis Workflow)

| Phase | Activity | Source Guidance |
| :--- | :--- | :--- |
| **Phase 1** | Requirements Analysis & Literature Review | Identify boundaries and system limits. |
| **Phase 2** | Smart Contract Development | Code the "promises" and execution rules in Solidity. |
| **Phase 3** | Java Middleware Integration | Build the bridge between IoT data and the ledger. |
| **Phase 4** | Simulation & Testing | Use synthetic sensor streams to verify system robustness. |
| **Phase 5** | Performance Evaluation | Measure accuracy, latency, and throughput of the network. |
| **Phase 6** | Thesis/Paper Submission | Target SCI/Scopus indexed journals for publication. |
